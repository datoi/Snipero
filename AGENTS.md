# Expo version

This project targets **Expo SDK 54** — `expo ~54.0.0`, React Native 0.81.5, React 19.1.
Those pins are in `package.json` and are the source of truth.

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any
code that touches Expo or React Native APIs. Do not follow guidance for a different SDK:
Expo's APIs move between majors, and the wrong version's docs are worse than none.

If the pinned version in `package.json` ever changes, update the link above in the same
commit — a stale version note here has already cost one round of confusion.
